# fib Model Code 2010 creep model documentation

This application implements the **normative creep-coefficient model in fib Model Code 2010 §5.1.9.4.3**: basic creep, drying creep, their sum, and the nonlinear correction when initial stress exceeds the linear range. JavaScript and Rust/WASM share the same parameter, boundary, and output contracts.

> Implementation boundary: the creep-coefficient path only; shrinkage, compliance, strength development, durability, and structural-response provisions are not included.

## Final publication and clause mapping

- fib (2013), *fib Model Code for Concrete Structures 2010*, Ernst & Sohn; the final two-volume edition was published in October 2013.
- Basic, drying, and total creep: §5.1.9.4.3, Eqs. 5.1-63–5.1-73.
- Nonlinear initial-stress correction: §5.1.9.4.3, Eq. 5.1-74.
- Temperature-adjusted age: Eq. 5.1-85; this application implements the scalar case of constant curing temperature.

## Input parameters and normative domain

| Interface meaning | Batch column | Unit | Requirement |
| --- | --- | --- | --- |
| Mean compressive strength | `fcm` | MPa | `20 ≤ fcm ≤ 130` |
| Relative humidity | `RH` | % | `40 ≤ RH ≤ 100` |
| Loading age | `t0` | d | `t0 ≥ 1` |
| Cross-sectional area | `Ac` | mm² | Positive |
| Drying perimeter | `u` | mm | Positive; use length units consistent with `Ac` |
| Constant curing temperature | `T` | °C | `5 ≤ T ≤ 30` |
| Cement strength class | `Cs` | — | `32.5 N/R`, `42.5 N/R`, `52.5 N/R` |
| Initial concrete stress | `sigma` | MPa | `\|sigma\| ≤ 0.6 fcm` |
| Target age | `t` | d | Measured from casting |

All ranges are actually validated. Invalid inputs return an error rather than extrapolated results. When `t ≤ t0`, all three creep outputs are 0.

## Cement-class coefficient

| `Cs` | `a` |
| --- | ---: |
| `32.5 N` | -1 |
| `32.5 R` | 0 |
| `42.5 N` | 0 |
| `42.5 R` | 1 |
| `52.5 N` | 1 |
| `52.5 R` | 1 |

Unrecognized cement classes cause an error; there is no implicit default.

## Equations

Temperature-adjusted age for constant temperature:

$
t_{0,T}=t_0\exp\left(13.65-\frac{4000}{273+T}\right)
$

Cement-class-adjusted loading age, with a lower bound of 0.5 d:

$
t_{0,adj}=\max\left\{t_{0,T}\left(\frac{9}{2+t_{0,T}^{1.2}}+1\right)^a,\ 0.5\right\}
$

Notional size, strength factor, and size parameter:

$
h=\frac{2A_c}{u},\qquad
\alpha_f=\sqrt{\frac{35}{f_{cm}}}
$

$
\beta_h=\min(1.5h+250\alpha_f,\ 1500\alpha_f)
$

The time difference is the duration since loading:

$
\Delta t=t-t_0
$

Basic creep:

$
\phi_{bc}=\frac{1.8}{f_{cm}^{0.7}}
\ln\left[\left(\frac{30}{t_{0,adj}}+0.035\right)^2\Delta t+1\right]
$

Drying creep:

$
\gamma(t_0)=\frac{1}{2.3+\frac{3.5}{\sqrt{t_{0,adj}}}}
$

$
\phi_{dc}=\frac{412}{f_{cm}^{1.4}}
\frac{1-RH/100}{(0.1h/100)^{1/3}}
\frac{1}{0.1+t_{0,adj}^{0.2}}
\left(\frac{\Delta t}{\beta_h+\Delta t}\right)^{\gamma(t_0)}
$

Nonlinear initial-stress correction:

$
k_\sigma=
\begin{cases}
1, & |\sigma|/f_{cm}\le0.4\\
\exp[1.5(|\sigma|/f_{cm}-0.4)], & 0.4<|\sigma|/f_{cm}\le0.6
\end{cases}
$

Total creep coefficient:

$
\phi(t,t_0)=(\phi_{bc}+\phi_{dc})k_\sigma
$

## Outputs

| Output column | Description |
| --- | --- |
| `result_phi` | Total creep coefficient `φ` after the nonlinear correction |
| `result_phi_bc` | Basic-creep component `φbc` |
| `result_phi_dc` | Drying-creep component `φdc` |
| `result_nonlinear_factor` | Nonlinear initial-stress factor `kσ` |

The single-point page plots total, basic, and drying creep over 0–10000 d. Batch calculation returns four outputs for each row's `t`; the header counts as the first row, and errors identify the data-row number.

## Documentation example comparison: DCE-MC1

The final fib text provides equations and applicability conditions but no complete numerical example that can be reproduced term by term. To avoid presenting a secondary implementation as official numerical data, this project uses the public example on pages 4 and 7–8 of the [SOFiSTiK Verification Manual DCE-MC1](https://docs.sofistik.com/2025/en/verification/_static/verification/pdf/dce-mc1.pdf) for an independent comparison. That document references MC2010 §5.1.9.4.3 and Eq. 5.1-85 equation by equation.

Example inputs: C35/45, `fcm=43 MPa`, `RH=80%`, a `1000×1000 mm` cross section (`Ac=1,000,000 mm²`, `u=4,000 mm`, `h=500 mm`), `t0=28 d`, `t=36,500 d`, `T=20°C`, N-class cement, and stresses in the linear range.

| Quantity | DCE-MC1 document value | Application JS | Application Rust/WASM | Difference explanation |
| --- | ---: | ---: | ---: | --- |
| `t0,adj` | 27.947 | 27.947490 | 27.947490 | Document rounds to 3 decimal places |
| `βbc(fcm)` | 0.12937 | 0.129373 | Same as JS | Document rounds to 5 decimal places |
| `βbc(t,t0)` | 10.71 | 10.710233 | Same as JS | Document rounds to 2 decimal places |
| `φbc` | 1.385 | 1.385618 | 1.385618 | Difference of 0.000618 |
| `βdc(fcm)` | 2.1283 | 2.128342 | Same as JS | Document rounds to 4 decimal places |
| `βdc(RH)` | Approximately 0.252 | 0.251984 | Same as JS | The document prints 0.251; its equation rounds to 0.252 |
| `βdc(t0)` | 0.4886 | 0.488624 | Same as JS | Document rounds to 4 decimal places |
| `γ(t0)` | 0.3376 | 0.337603 | Same as JS | Document rounds to 4 decimal places |
| `βh` | 975.548 | 975.548427 | Same as JS | Document rounds to 3 decimal places |

Page 8 contains two typesetting/rounding inconsistencies: the drying-creep result is mislabeled `φbc`; the preceding line gives `φdc=0.2597`, but the total line uses `0.2587`. This application uses unrounded intermediate values and reports the original MC2010 `φ` based on tangent modulus `Ec`. The final `1.56/1.563` in that document is the value SOFiSTiK obtains after an additional division by 1.05 for its `Ecm` calculation system.

## Unimplemented provisions

- The piecewise temperature history of Eq. 5.1-85 is not implemented; `T` is constant throughout the period before loading.
- Extreme-temperature effects under §5.1.10.7 are not implemented. Inputs outside 5–30°C cannot be used as a substitute for that provision.
- MC2010 shrinkage, compliance, and other material or structural models are outside this calculator's scope.
- Results do not replace project material testing, model calibration, structural analysis, or professional engineering judgment.
