# RILEM Model B4 documentation: multi-decade creep and shrinkage of concrete

This project implements the mix-composition-based mean-prediction **Model B4** formally recommended by **RILEM TC-242-MDC (2015)** (*Materials and Structures* 48(4):753–770, DOI: 10.1617/s11527-014-0485-2).

The model returns:
1. **Compliance function $J(t,t')$** (total elastic-plus-creep strain under unit stress)
2. **Drying-shrinkage strain $\varepsilon_{sh}$**
3. **Autogenous-shrinkage strain $\varepsilon_{au}$**
4. **Total shrinkage strain $\varepsilon_{sh,total} = \varepsilon_{sh} + \varepsilon_{au}$**

## 2. Units and output conventions

The application kernels use standard physical units:
- Compliance $J(t,t')$: internally $1/\text{MPa}$ (typically of order $10^{-4}$, corresponding to $10^{-6}/\text{MPa} = \mu\text{strain}/\text{MPa}$ values of approximately $100$).
- Public outputs and charts convert consistently to **$1/\text{GPa}$** ($1/\text{GPa} = 1000 \times 10^{-6}/\text{MPa}$) and microstrain $\mu\varepsilon$:
  $$\text{J (1/GPa)} = J \times 1000$$
- Shrinkage strains ($\varepsilon_{sh}$, $\varepsilon_{au}$, $\varepsilon_{sh,total}$) are returned as dimensionless strain; charts display microstrain $\mu\varepsilon$ ($10^{-6}$).

## 3. Core equations (RILEM TC-242-MDC 2015)

### 3.1 Stage-specific temperature acceleration and equivalent ages (Eqs. 8–10, 39)

$$\beta_{Th} = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_{cur} + 273}\right)\right]$$

$$\beta_{Ts} = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_{sh} + 273}\right)\right]$$

$$\beta_{Tc} = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_c + 273}\right)\right]$$

$$\tilde{t}_0 = t_0 \beta_{Th},\quad \tilde{t} = \max(0, t - t_0)\beta_{Ts}$$

$$\hat{t}' = t_0 \beta_{Th} + (t' - t_0)\beta_{Ts},\quad \hat{t} = \hat{t}' + (t - t')\beta_{Tc}$$

$$R_T = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_c + 273}\right)\right]$$

### 3.2 Elastic modulus and instantaneous compliance (Eqs. 28–29)

$$E_{28} = 4734\sqrt{f_c} \text{ (MPa)}$$

$$q_1 = \frac{p_1}{E_{28}} \text{ (1/MPa)}$$

### 3.3 Basic creep $C_0$ (Eqs. 30–35)

$$C_0(\hat{t}, \hat{t}') = q_2 Q(\hat{t}, \hat{t}') + q_3 \ln\left[1 + (\hat{t} - \hat{t}')^{0.1}\right] + q_4 \ln\left(\frac{\hat{t}}{\hat{t}'}\right)$$

$$Q(\hat{t}, \hat{t}') = Q_f \left[1 + \left(\frac{Q_f}{Z}\right)^r\right]^{-1/r}$$

$$Q_f = \frac{1}{0.086 \hat{t}'^{2/9} + 1.21 \hat{t}'^{4/9}},\quad Z = \hat{t}'^{-0.5} \ln\left[1 + (\hat{t} - \hat{t}')^{0.1}\right],\quad r = 1.7\hat{t}'^{0.12} + 8$$

### 3.4 Drying creep $C_d$ (Eqs. 36–38)

$$C_d(\hat{t}, \hat{t}', \tilde{t}_0) = q_5 \sqrt{\max\left(0, e^{-p_{5H} H} - e^{-p_{5H} H_c}\right)}$$

$$H = 1 - (1 - h)\tanh\sqrt{\frac{\max(0, \hat{t} - \tilde{t}_0)}{\tau_{sh}}},\quad H_c = 1 - (1 - h)\tanh\sqrt{\frac{\max(0, \max(\hat{t}', \tilde{t}_0) - \tilde{t}_0)}{\tau_{sh}}}$$

### 3.5 Drying shrinkage $\varepsilon_{sh}$ and autogenous shrinkage $\varepsilon_{au}$ (Eqs. 13–26)

$$\varepsilon_{sh} = \varepsilon_{sh\infty} k_h \tanh\sqrt{\frac{\tilde{t}}{\tau_{sh}}}$$

$$\varepsilon_{au} = \varepsilon_{au\infty}\left[1 + \left(\frac{\tau_{au}}{\tilde{t} + \tilde{t}_0}\right)^{\alpha_{au}}\right]^{r_t}$$

$$\varepsilon_{sh,total} = \varepsilon_{sh} + \varepsilon_{au}$$

Total compliance:

$$J(t, t') = q_1 + R_T C_0 + C_d$$

## 4. Reproduction and comparison of the official §1.9 example

Pages 764–767 of the original RILEM B4 paper provide the official benchmark:
- Inputs: R-class cement, no special admixtures specified, No Information aggregate, slab specimen (ks=1), $t=112\text{ d}$, $t'=28\text{ d}$, $t_0=28\text{ d}$, $h=50\%$, $f_c=27.6\text{ MPa}$, $V/S=19.05\text{ mm}$, $c=219.3\text{ kg/m³}$, $w/c=0.60$, $a/c=7.0$, $T=20^\circ\text{C}$.

| Output quantity | Official paper value (§1.9) | Application JS / Rust kernels | Agreement |
| --- | ---: | ---: | --- |
| Instantaneous compliance $q_1$ | $28.15 \times 10^{-6} /\text{MPa}$ | $28.1459 \times 10^{-6} /\text{MPa}$ | Close agreement |
| Basic creep $C_0$ | $59.95 \times 10^{-6} /\text{MPa}$ | $59.9519 \times 10^{-6} /\text{MPa}$ | Close agreement |
| Drying creep $C_d$ | $81.44 \times 10^{-6} /\text{MPa}$ | $81.4428 \times 10^{-6} /\text{MPa}$ | Close agreement |
| Total compliance $J$ | $169.5 \times 10^{-6} /\text{MPa}$ (0.1695 /GPa) | $169.5406 \times 10^{-6} /\text{MPa}$ | Close agreement |
| Drying shrinkage $\varepsilon_{sh}$ | $-434.7 \times 10^{-6}$ | $-434.7418 \times 10^{-6}$ | Close agreement |
| Autogenous shrinkage $\varepsilon_{au}$ | $-36.97 \times 10^{-6}$ | $-36.9710 \times 10^{-6}$ | Close agreement |
| Total shrinkage $\varepsilon_{sh,total}$ | $-471.7 \times 10^{-6}$ | $-471.7128 \times 10^{-6}$ | Close agreement |
