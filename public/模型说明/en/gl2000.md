# GL2000 creep and shrinkage model documentation

This application uses the GL2000 model of Gardner and Lockman to calculate creep compliance `J(t,t0)` and drying-shrinkage strain `εsh(t,tc)`. Input time `t` is concrete age measured from casting; creep duration is `t - t0`, and drying duration is `t - tc`.

| Item | Information | Official source |
| --- | --- | --- |
| Original paper | **Gardner N.J., Lockman M.J. (2001)**, *Design Provisions for Drying Shrinkage and Creep of Normal-Strength Concrete*; ACI Materials Journal, 98(2), 159–167 | Paywalled original; authoritative citation source |
| Committee guide | **ACI 209.2R-08**, *Guide for Modeling and Calculating Shrinkage and Creep in Hardened Concrete*; Appendix A.4 provides the GL2000 equations and cement-coefficient Table A.14 | [ACI official guide PDF][1] |

## Model scope

GL2000 is strength-based and does not require mix composition, only the 28-day mean compressive strength. Its domain, as summarized by Al-Manaseer & Prado (2015), is: [Source: paper available from the author's SJSU page][2]

- 28-day mean cylinder compressive strength: **16–82 MPa**.
- Ambient relative humidity: **20–100%**. Use **96%** for sealed specimens (the equation naturally reaches zero at 96%; this is an intended zero, not a fitted adjustment).
- Cement types I, II, III (coefficients `K = 1.00 / 0.75 / 1.15` and strength-development rates `s = 0.335 / 0.40 / 0.13`).
- Loading must not precede the start of drying (`t0 ≥ tc`). Otherwise the preloading drying correction `Φ(tc)` is undefined, and the application reports an error rather than a numerical result.

This application implements both creep (compliance) and drying shrinkage. There is no autogenous-shrinkage term (`εau` is always 0, retained only to align the batch matrix with B4 columns).

## Input parameters

| Interface meaning | Batch column | Unit | Description |
| --- | --- | --- | --- |
| Cement type | `cementType` | - | `I`, `II`, or `III` |
| 28-day mean strength | `fcm28` | MPa | Mean cylinder compressive strength, 16–82 |
| Relative humidity | `h` | % | Ambient relative humidity, 20–100; use 96 for sealed concrete |
| Volume-to-surface ratio | `vs` | mm | Member volume divided by exposed surface area |
| Age at start of drying | `tc` | d | Age at start of drying (end of curing) |
| Loading age | `t0` | d | Concrete age at first loading; must be ≥ tc |
| Calculation age | `t` | d | Target age measured from casting |

When `t <= tc`, drying has not begun and shrinkage is 0. When `t <= t0`, loading has not begun and compliance remains at the elastic value `1/Ecmto`.

## Equations

Compliance is the elastic term plus the creep term; the creep coefficient contains basic and drying components (Gardner appendix `[A5][A6]`):

```math
J(t,t_0)=\frac{1}{E_{cmto}}+\frac{\phi_{28}}{E_{cm28}}
```

```math
\phi_{28}=\Phi(t_c)\cdot(\mathrm{basic}+\mathrm{drying})
```

```math
E_{cmt}=3500+4300\sqrt{f_{cmt}},\quad f_{cmt}=f_{cm28}\exp\left[s\left(1-\sqrt{28/t}\right)\right]
```

```math
\Phi(t_c)=1\ (t_0=t_c)
```

Drying shrinkage is the ultimate value multiplied by humidity and time factors (ACI 209.2R-08 Appendix A.4):

```math
\varepsilon_{sh}=\varepsilon_{shu}\beta(h)\beta(t)
```

```math
\varepsilon_{shu}=900K\left(\frac{30}{f_{cm28}}\right)^{1/2}\!\times\!10^{-6}
```

```math
\beta(h)=1-1.18h^4,\quad \beta(t)=\left(\frac{t-t_c}{(t-t_c)+0.12(V/S)^2}\right)^{1/2}
```

The application uses negative shrinkage (shortening is negative, consistently with B4/B4s); the literature prints positive magnitudes.

## Output definitions

| Output | Unit | Description |
| --- | --- | --- |
| `J(t,t0)` | 1/GPa (internally 1/MPa) | Compliance: elastic + basic creep + drying creep |
| `εsh` | µε (negative) | Drying-shrinkage strain |
| `εau` | µε | Always 0 (the model has no autogenous term; retained for matrix alignment) |
| `εsh,total` | µε (negative) | Total shrinkage, equal to drying shrinkage here |

Single-point calculation generates a concrete-age curve from 0 to 10000 days; batch calculation returns a result for each row's `t`.

## Limitations

- The GL2000 creep example table in guide C.4 contradicts its own appendix equations: components are combined inconsistently, the drying term is omitted, and the Φ and βs values do not match the example's inputs. It cannot serve as a validation target. The application implements creep from Gardner's own appendix `[A5][A6]` and validates against the exact C.4.4 elastic chain and structural properties of the equations. See the evidence record in repository file `docs/benchmark-sources.md`.
- Type II cement coefficient K is 0.75, following guide Table A.14 and Gardner's appendix. The 0.70 printed in Auburn report Eq. 3.189 is an isolated transcription error.
- This calculator provides empirical model predictions, not a substitute for material testing, project-specific analysis, or the judgment of a licensed engineer.
