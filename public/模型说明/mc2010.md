# fib Model Code 2010 徐变模型说明

当前应用实现 **fib Model Code 2010 §5.1.9.4.3 的正式徐变系数模型**：基本徐变、干燥徐变、两者之和，以及初始应力超过线性范围时的非线性修正。JavaScript 与 Rust/WASM 使用同一参数、边界和输出契约。

> 实现边界：仅包含徐变系数路径；不包含收缩、柔量、强度发展、耐久性或结构响应条款。

## 正式出版物与条文映射

- fib (2013), *fib Model Code for Concrete Structures 2010*, Ernst & Sohn，最终两卷本于 2013 年 10 月出版。
- 基本徐变、干燥徐变和总徐变：§5.1.9.4.3，Eqs. 5.1-63–5.1-73。
- 非线性初始应力修正：§5.1.9.4.3，Eq. 5.1-74。
- 温度修正龄期：Eq. 5.1-85；本应用实现恒定养护温度的标量情形。

## 输入参数与正式适用范围

| 界面含义 | 批量列名 | 单位 | 要求 |
| --- | --- | --- | --- |
| 平均抗压强度 | `fcm` | MPa | `20 ≤ fcm ≤ 130` |
| 相对湿度 | `RH` | % | `40 ≤ RH ≤ 100` |
| 加载龄期 | `t0` | d | `t0 ≥ 1` |
| 截面面积 | `Ac` | mm² | 正值 |
| 干燥周长 | `u` | mm | 正值，与 `Ac` 长度单位一致 |
| 恒定养护温度 | `T` | °C | `5 ≤ T ≤ 30` |
| 水泥强度等级 | `Cs` | — | `32.5 N/R`、`42.5 N/R`、`52.5 N/R` |
| 初始混凝土应力 | `sigma` | MPa | `|sigma| ≤ 0.6 fcm` |
| 目标龄期 | `t` | d | 从浇筑起算 |

所有范围都会被实际校验；无效输入不会外推，而是返回错误。`t ≤ t0` 时三个徐变输出均为 0。

## 水泥等级系数

| `Cs` | `a` |
| --- | ---: |
| `32.5 N` | -1 |
| `32.5 R` | 0 |
| `42.5 N` | 0 |
| `42.5 R` | 1 |
| `52.5 N` | 1 |
| `52.5 R` | 1 |

未识别的水泥等级直接报错，不采用隐式默认值。

## 计算公式

恒定温度下的温度修正龄期：

$
t_{0,T}=t_0\exp\left(13.65-\frac{4000}{273+T}\right)
$

水泥等级修正后的加载龄期，下限为 0.5 d：

$
t_{0,adj}=\max\left\{t_{0,T}\left(\frac{9}{2+t_{0,T}^{1.2}}+1\right)^a,\ 0.5\right\}
$

名义尺寸、强度系数和尺寸参数：

$
h=\frac{2A_c}{u},\qquad
\alpha_f=\sqrt{\frac{35}{f_{cm}}}
$

$
\beta_h=\min(1.5h+250\alpha_f,\ 1500\alpha_f)
$

时间差使用从加载开始的持续时间：

$
\Delta t=t-t_0
$

基本徐变：

$
\phi_{bc}=\frac{1.8}{f_{cm}^{0.7}}
\ln\left[\left(\frac{30}{t_{0,adj}}+0.035\right)^2\Delta t+1\right]
$

干燥徐变：

$
\gamma(t_0)=\frac{1}{2.3+\frac{3.5}{\sqrt{t_{0,adj}}}}
$

$
\phi_{dc}=\frac{412}{f_{cm}^{1.4}}
\frac{1-RH/100}{(0.1h/100)^{1/3}}
\frac{1}{0.1+t_{0,adj}^{0.2}}
\left(\frac{\Delta t}{\beta_h+\Delta t}\right)^{\gamma(t_0)}
$

初始应力非线性修正：

$
k_\sigma=
\begin{cases}
1, & |\sigma|/f_{cm}\le0.4\\
\exp[1.5(|\sigma|/f_{cm}-0.4)], & 0.4<|\sigma|/f_{cm}\le0.6
\end{cases}
$

总徐变系数：

$
\phi(t,t_0)=(\phi_{bc}+\phi_{dc})k_\sigma
$

## 输出

| 输出列 | 说明 |
| --- | --- |
| `result_phi` | 应用非线性修正后的总徐变系数 `φ` |
| `result_phi_bc` | 基本徐变分量 `φbc` |
| `result_phi_dc` | 干燥徐变分量 `φdc` |
| `result_nonlinear_factor` | 非线性初始应力系数 `kσ` |

单点页面绘制 0–10000 d 的总徐变、基本徐变和干燥徐变曲线。批量计算按每行的 `t` 返回四个输出；首行按表头计数，错误会指出数据行号。

## 文档算例对比：DCE-MC1

fib 最终版正文给出公式和适用条件，但没有提供一组可逐项复算的完整数值算例。为避免把二次实现当作官方数值，本项目另用 [SOFiSTiK Verification Manual DCE-MC1](https://docs.sofistik.com/2025/en/verification/_static/verification/pdf/dce-mc1.pdf) 第 4、7–8 页的公开算例做独立对比。该文档逐式引用 MC2010 §5.1.9.4.3 和 Eq. 5.1-85。

算例输入：C35/45，`fcm=43 MPa`，`RH=80%`，截面 `1000×1000 mm`（`Ac=1,000,000 mm²`、`u=4,000 mm`、`h=500 mm`），`t0=28 d`，`t=36,500 d`，`T=20°C`，N 类水泥，线性应力范围。

| 项目 | DCE-MC1 文档值 | 本应用 JS | 本应用 Rust/WASM | 差异说明 |
| --- | ---: | ---: | ---: | --- |
| `t0,adj` | 27.947 | 27.947490 | 27.947490 | 文档保留 3 位小数 |
| `βbc(fcm)` | 0.12937 | 0.129373 | 同 JS | 文档保留 5 位小数 |
| `βbc(t,t0)` | 10.71 | 10.710233 | 同 JS | 文档保留 2 位小数 |
| `φbc` | 1.385 | 1.385618 | 1.385618 | 差 0.000618 |
| `βdc(fcm)` | 2.1283 | 2.128342 | 同 JS | 文档保留 4 位小数 |
| `βdc(RH)` | 约 0.252 | 0.251984 | 同 JS | 文档正文显示 0.251，按其公式应四舍五入为 0.252 |
| `βdc(t0)` | 0.4886 | 0.488624 | 同 JS | 文档保留 4 位小数 |
| `γ(t0)` | 0.3376 | 0.337603 | 同 JS | 文档保留 4 位小数 |
| `βh` | 975.548 | 975.548427 | 同 JS | 文档保留 3 位小数 |
| `βdc(t,t0)` | 0.9911 | 0.991128 | 同 JS | 文档保留 4 位小数 |
| `φdc` | 0.2597 | 0.259728 | 0.259728 | 差 0.000028 |
| `φ=φbc+φdc` | 1.64 | 1.645346 | 1.645346 | 文档仅显示 2 位小数 |
| 按 `Ecm` 换算 `φ/1.05` | 1.56；结果表 1.563 | 1.566996 | 1.566996 | 相对结果表差 0.256% |

文档第 8 页存在两个排版/舍入不一致：干燥徐变结果被误标为 `φbc`；上一行给出 `φdc=0.2597`，总和行却写成 `0.2587`。本应用采用未舍入中间量，且输出的是 MC2010 基于切线模量 `Ec` 的原始 `φ`；文档最后的 `1.56/1.563` 是 SOFiSTiK 为其 `Ecm` 计算体系额外除以 1.05 后的值。

## 未实现边界

- Eq. 5.1-85 的分段温度历程未实现；`T` 被视为加载前全程恒定。
- §5.1.10.7 的极端温度效应未实现，因此不允许用超出 5–30°C 的输入冒充该条款。
- MC2010 的收缩、柔量和其他材料或结构模型不在本计算器范围内。
- 结果不能替代项目材料试验、模型校准、结构分析或专业工程判断。
