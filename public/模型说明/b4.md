# RILEM Model B4 混凝土多年代徐变与收缩模型说明

本项目严格实现 **RILEM TC-242-MDC (2015)** 正式推荐的 **Model B4** 配合比基准平均预测模型（*Materials and Structures* 48(4):753–770, DOI: 10.1617/s11527-014-0485-2）。

该模型输出：
1. **柔度函数 $J(t,t')$**（单位应力下的总弹性加徐变应变）
2. **干燥收缩应变 $\varepsilon_{sh}$**
3. **自生收缩应变 $\varepsilon_{au}$**
4. **总收缩应变 $\varepsilon_{sh,total} = \varepsilon_{sh} + \varepsilon_{au}$**

## 2. 单位与输出规范

本应用内核严格采用国际标准物理单位：
- 柔度函数 $J(t,t')$：内部计算单位为 $1/\text{MPa}$（数值约为 $10^{-4}$，对应 $10^{-6}/\text{MPa} = \mu\text{strain}/\text{MPa}$ 约为 $100$）。
- 公开输出与图表统一换算为 **$1/\text{GPa}$**（$1/\text{GPa} = 1000 \times 10^{-6}/\text{MPa}$）以及微应变 $\mu\varepsilon$：
  $$\text{J (1/GPa)} = J \times 1000$$
- 收缩应变（$\varepsilon_{sh}$、$\varepsilon_{au}$、$\varepsilon_{sh,total}$）：以无量纲应变输出，图表以微应变 $\mu\varepsilon$（$10^{-6}$）展示。

## 3. 核心数学公式 (RILEM TC-242-MDC 2015)

### 3.1 阶段温度加速与等效龄期 (Eqs. 8–10, 39)

$$\beta_{Th} = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_{cur} + 273}\right)\right]$$

$$\beta_{Ts} = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_{sh} + 273}\right)\right]$$

$$\beta_{Tc} = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_c + 273}\right)\right]$$

$$\tilde{t}_0 = t_0 \beta_{Th},\quad \tilde{t} = \max(0, t - t_0)\beta_{Ts}$$

$$\hat{t}' = t_0 \beta_{Th} + (t' - t_0)\beta_{Ts},\quad \hat{t} = \hat{t}' + (t - t')\beta_{Tc}$$

$$R_T = \exp\left[4000\left(\frac{1}{293} - \frac{1}{T_c + 273}\right)\right]$$

### 3.2 弹性模量与瞬时柔度 (Eqs. 28–29)

$$E_{28} = 4734\sqrt{f_c} \text{ (MPa)}$$

$$q_1 = \frac{p_1}{E_{28}} \text{ (1/MPa)}$$

### 3.3 基本徐变 $C_0$ (Eqs. 30–35)

$$C_0(\hat{t}, \hat{t}') = q_2 Q(\hat{t}, \hat{t}') + q_3 \ln\left[1 + (\hat{t} - \hat{t}')^{0.1}\right] + q_4 \ln\left(\frac{\hat{t}}{\hat{t}'}\right)$$

$$Q(\hat{t}, \hat{t}') = Q_f \left[1 + \left(\frac{Q_f}{Z}\right)^r\right]^{-1/r}$$

$$Q_f = \frac{1}{0.086 \hat{t}'^{2/9} + 1.21 \hat{t}'^{4/9}},\quad Z = \hat{t}'^{-0.5} \ln\left[1 + (\hat{t} - \hat{t}')^{0.1}\right],\quad r = 1.7\hat{t}'^{0.12} + 8$$

### 3.4 干燥徐变 $C_d$ (Eqs. 36–38)

$$C_d(\hat{t}, \hat{t}', \tilde{t}_0) = q_5 \sqrt{\max\left(0, e^{-p_{5H} H} - e^{-p_{5H} H_c}\right)}$$

$$H = 1 - (1 - h)\tanh\sqrt{\frac{\max(0, \hat{t} - \tilde{t}_0)}{\tau_{sh}}},\quad H_c = 1 - (1 - h)\tanh\sqrt{\frac{\max(0, \max(\hat{t}', \tilde{t}_0) - \tilde{t}_0)}{\tau_{sh}}}$$

### 3.5 干燥收缩 $\varepsilon_{sh}$ 与自生收缩 $\varepsilon_{au}$ (Eqs. 13–26)

$$\varepsilon_{sh} = \varepsilon_{sh\infty} k_h \tanh\sqrt{\frac{\tilde{t}}{\tau_{sh}}}$$

$$\varepsilon_{au} = \varepsilon_{au\infty}\left[1 + \left(\frac{\tau_{au}}{\tilde{t} + \tilde{t}_0}\right)^{\alpha_{au}}\right]^{r_t}$$

$$\varepsilon_{sh,total} = \varepsilon_{sh} + \varepsilon_{au}$$

总柔度函数：

$$J(t, t') = q_1 + R_T C_0 + C_d$$
