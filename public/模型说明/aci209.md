# ACI 209R-92 徐变模型说明

本应用按 ACI 209R-92 计算湿养护或蒸汽养护混凝土的徐变系数 `φ(t,t0)`。输入时间 `t` 是从浇筑起算的混凝土龄期，徐变发展时间为 `t - t0`。

## 模型范围

ACI 209R-92 报告讨论徐变、收缩、温度作用，以及强度和弹性模量随龄期的发展。本页面只实现报告中的**徐变系数**路径，不包含收缩、强度发展、弹性模量、老化系数或结构响应计算。[来源：ACI 209R-92 官方说明][1]

ACI 209.2R-08 给出的模型范围和使用条件包括：[来源：ACI 209.2R-08 §1.2][3]

- 用于硬化混凝土受压徐变和收缩预测；可假定预测适用于受拉和受剪情况。
- 模型面向至少湿养护 1 天、在养护结束或之后加载的混凝土。
- 适用的 28 天平均圆柱抗压强度范围至少为 **20–70 MPa（3000–10000 psi）**。
- 模型按典型组成混凝土标定；对硅灰、粉煤灰掺量超过 30% 或天然火山灰混凝土，应使用实际材料试验校准。
- 对徐变和收缩敏感的结构，ACI 建议使用实际混凝土试验数据校准模型，而不是只依赖经验预测。

## 输入参数

| 界面含义 | 批量列名 | 单位 | 说明 |
| --- | --- | --- | --- |
| 养护方式 | `curingType` | - | `moist`（湿养护）或 `steam`（蒸汽养护） |
| 加载龄期 | `t0` | d | 混凝土开始受荷时的龄期 |
| 相对湿度 | `H` | % | 环境相对湿度 |
| 体积表面积比 | `VS` | mm | 构件体积与暴露表面积之比 |
| 坍落度 | `slump` | mm | 新拌混凝土坍落度 |
| 细骨料百分比 | `fineAggregate` | % | 细骨料占总骨料的质量百分比 |
| 含气量 | `airContent` | % | 混凝土含气量 |
| 计算龄期 | `t` | d | 从浇筑起算的目标龄期 |

当 `t <= t0` 时，徐变尚未开始，应用返回 `φ = 0`。

## 计算公式

ACI 209R-92 Eq. (2-8) 使用加载后的持续时间计算徐变发展：[来源：ACI 209R-92 §2.4、Eq. (2-8)][1]

```math
\phi(t,t_0)=\frac{(t-t_0)^{0.6}}{10+(t-t_0)^{0.6}}\phi_u
```

终极徐变系数采用基准值 2.35，并乘以加载龄期、湿度、构件尺寸、坍落度、细骨料和含气量修正项：[来源：ACI 209R-92 §2.5–2.6；ACI 209.2R-08 Appendix A.1][1][3]

```math
\phi_u=2.35\gamma_{la}\gamma_{RH}\gamma_{V/S}\gamma_s\gamma_\psi\gamma_\alpha
```

### 加载龄期修正

```math
\gamma_{la}=\begin{cases}
1, & \text{湿养护且 }t_0\le7\text{ d}\\
1.25t_0^{-0.118}, & \text{湿养护且 }t_0>7\text{ d}\\
1, & \text{蒸汽养护且 }t_0\le3\text{ d}\\
1.13t_0^{-0.094}, & \text{蒸汽养护且 }t_0>3\text{ d}
\end{cases}
```

### 相对湿度修正

```math
\gamma_{RH}=\begin{cases}
1, & H\le40\%\\
1.27-0.0067H, & H>40\%
\end{cases}
```

### 构件尺寸修正

`VS` 为体积与暴露表面积之比，单位为 mm：

```math
\gamma_{V/S}=\frac{2}{3}\left[1+1.13e^{-0.0213(V/S)}\right]
```

### 混凝土组成修正

坍落度使用 mm，细骨料和含气量使用百分数：[来源：ACI 209R-92 §2.6；ACI 209.2R-08 Appendix A.1][1][3]

```math
\gamma_s=0.82+0.00264s_{mm}
```

```math
\gamma_\psi=0.88+0.0024\psi_{\%}
```

```math
\gamma_\alpha=\max\left(1,0.46+0.09\alpha_{\%}\right)
```

水泥用量修正属于 ACI 209R-92 **收缩模型**，不参与上述徐变系数计算。

## 输出定义

| 输出 | 单位 | 说明 |
| --- | --- | --- |
| `φ(t,t0)` | - | 徐变应变与加载时初始应变之比 |

单点计算生成 0 到 10000 天的混凝土龄期曲线；批量计算按每行的 `t` 输出一个结果。

## 使用限制

- ACI 将该类文件定义为委员会报告/指南，而不是可直接写入合同文件的强制性规范条文；如需形成合同要求，应由负责工程师转写为强制性条款。[来源：ACI 209.2R-08 首页声明][3]
- 徐变试验与预测具有较大离散性。ACI 209.2R-08 明确指出，徐变预测与试验结果的差异可能大于收缩预测；关键结构应开展材料试验并据此外推长期行为。[来源：ACI 209.2R-08 §1.1][3]
- 本计算器给出经验模型预测，不替代材料试验、项目专项分析或注册工程师判断。
- 本页面不计算徐变应变本身。若需要徐变应变，还需使用加载应力及加载龄期弹性模量，并保持单位一致。
