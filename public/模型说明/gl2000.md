# GL2000 徐变与收缩模型说明

本应用按 Gardner 与 Lockman 的 GL2000 模型计算徐变柔量 `J(t,t0)` 与干燥收缩应变 `εsh(t,tc)`。输入时间 `t` 是从浇筑起算的混凝土龄期，徐变发展时间为 `t - t0`，干燥时间为 `t - tc`。

## 模型范围

GL2000 是强度基准模型，不需要配合比，只需要 28 天平均抗压强度。适用域（Al-Manaseer & Prado 2015 汇总）：[来源：作者 SJSU 主页公开论文][2]

- 28 天平均圆柱抗压强度 **16–82 MPa**。
- 环境相对湿度 **20–100%**；密封试件按 **96%** 计（公式在 96% 处自然归零，这是设计好的零点，不是拟合）。
- 水泥类型 I、II、III（对应系数 `K = 1.00 / 0.75 / 1.15`，强度发展速率 `s = 0.335 / 0.40 / 0.13`）。
- 加载龄期不早于干燥开始（`t0 ≥ tc`），否则干燥前加载修正 `Φ(tc)` 无定义，应用会直接报错而不是给出数字。

本应用实现徐变（柔量）与干燥收缩两半，没有自生收缩项（`εau` 恒为 0，只是为了让批量矩阵与 B4 列对齐）。

## 输入参数

| 界面含义 | 批量列名 | 单位 | 说明 |
| --- | --- | --- | --- |
| 水泥类型 | `cementType` | - | `I`、`II` 或 `III` |
| 28 天平均强度 | `fcm28` | MPa | 圆柱体平均抗压强度，16–82 |
| 相对湿度 | `h` | % | 环境相对湿度，20–100；密封取 96 |
| 体积表面积比 | `vs` | mm | 构件体积与暴露表面积之比 |
| 干燥开始龄期 | `tc` | d | 干燥（养护结束）开始时的龄期 |
| 加载龄期 | `t0` | d | 混凝土开始受荷时的龄期，须 ≥ tc |
| 计算龄期 | `t` | d | 从浇筑起算的目标龄期 |

当 `t <= tc` 时尚未开始干燥，收缩为 0；当 `t <= t0` 时尚未加载，柔量恒为弹性值 `1/Ecmto`。

## 计算公式

柔量为弹性项加徐变项，徐变系数分为基本徐变与干燥徐变两部分（Gardner 附录 `[A5][A6]`）：

```math
J(t,t_0)=\frac{1}{E_{cmto}}+\frac{\phi_{28}}{E_{cm28}}
```

```math
\phi_{28}=\Phi(t_c)\cdot(\mathrm{basic}+\mathrm{drying})
```

```math
E_{cmt}=3500+4300\sqrt{f_{cmt}},\quad f_{cmt}=f_{cm28}\exp\left[s\left(1-\sqrt{28/t}\right)\right]
```

```math
\Phi(t_c)=1\ (t_0=t_c)
```

干燥收缩为终值乘湿度、时间两项（ACI 209.2R-08 Appendix A.4）：

```math
\varepsilon_{sh}=\varepsilon_{shu}\beta(h)\beta(t)
```

```math
\varepsilon_{shu}=900K\left(\frac{30}{f_{cm28}}\right)^{1/2}\!\times\!10^{-6}
```

```math
\beta(h)=1-1.18h^4,\quad \beta(t)=\left(\frac{t-t_c}{(t-t_c)+0.12(V/S)^2}\right)^{1/2}
```

应用内收缩取负号（缩短为负，与 B4/B4s 一致），文献中均以正值印刷。

## 输出定义

| 输出 | 单位 | 说明 |
| --- | --- | --- |
| `J(t,t0)` | 1/GPa（内部 1/MPa） | 柔量：弹性 + 基本徐变 + 干燥徐变 |
| `εsh` | µε（负值） | 干燥收缩应变 |
| `εau` | µε | 恒为 0（模型无自生项，为对齐矩阵保留） |
| `εsh,total` | µε（负值） | 总收缩（此处等于干燥收缩） |

单点计算生成 0 到 10000 天的混凝土龄期曲线；批量计算按每行的 `t` 输出一个结果。

## 使用限制

- 指南 C.4 的 GL2000 徐变例题表与其附录方程自相矛盾（子项各自精确但按和组合、漏掉干燥项、Φ 与 βs 数值对不上例题自带输入），不能作为验证目标；本应用徐变半依据 Gardner 本人附录 `[A5][A6]` 实现，以 C.4.4 弹性链精确值与方程结构性质验证。详见仓库 `docs/benchmark-sources.md` 取证记录。
- II 型水泥系数 K 取指南 Table A.14 与 Gardner 附录的 0.75；Auburn 报告 Eq 3.189 印 0.70，为孤证误抄。
- 本计算器给出经验模型预测，不替代材料试验、项目专项分析或注册工程师判断。
