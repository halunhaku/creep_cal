# AASHTO LRFD 徐变与收缩模型说明

本应用按 AASHTO LRFD（NCHRP 18-07，经 FHWA-HRT-05-057 修订提案写入规范 5.4.2.3）计算徐变系数 `ψ(t,ti)` 与收缩应变 `εsh`。输入时间 `t` 是从浇筑起算的混凝土龄期，徐变发展时间为 `t - ti`，干燥时间为 `t - tc`。

| 独立转录 | **Auburn ALDOT 930989 §3.2.1**，Eqs. 3.1–3.8，同一套方程的文字版 | [Auburn 报告 PDF][2] |
| 适用对象 | 除节段拼装桥之外的桥梁；节段桥需要项目专项标定 | [同上][1] |

## 模型范围

条文适用的设计强度见 5.4.2.1（本应用按 2.4–15 KSI 执行）。条文自己写明：在没有试验或经验的情况下，经验方法的误差要按 ±50% 预期。[来源：FHWA C5.4.2.3][1]

校准锚点（FHWA 背景原文）：`f'ci = 4 KSI、H = 70%、V/S = 3.5 in` 时全部修正因子为 1。本应用的单元测试直接钉住这组锚点。

## 输入参数

| 界面含义 | 批量列名 | 单位 | 说明 |
| --- | --- | --- | --- |
| 加载时强度 | `fci` | MPa | 加载/张拉时的强度，16.5–103.5（2.4–15 KSI） |
| 相对湿度 | `H` | % | 年平均环境湿度，0–100 |
| 体积表面积比 | `vs` | mm | 只计暴露干燥的表面积；上限按规范取 6.0 in |
| 加载龄期 | `ti` | d | 初次加载龄期，≥ 1 |
| 养护结束龄期 | `tc` | d | 干燥开始龄期；早于 5 天干燥收缩结果 ×1.2 |
| 计算龄期 | `t` | d | 从浇筑起算的目标龄期 |

当 `t <= ti` 时徐变系数为 0；当 `t <= tc` 时收缩为 0。

## 计算公式

徐变系数（5.4.2.3.2-1）：[来源：FHWA Appendix D][1]

```math
\psi(t,t_i)=1.9k_sk_{hc}k_fk_{td}t_i^{-0.118}
```

```math
k_s=\max(1.0,1.45-0.13(V/S)_{in}),\quad k_{hc}=1.56-0.008H
```

```math
k_f=\frac{5}{1+f'_{ci}},\quad k_{td}=\frac{t}{61-4f'_{ci}+t}
```

收缩应变（5.4.2.3.3-1），其中湿度项换为 `khs`，其余与徐变共用：[来源：同上][1]

```math
\varepsilon_{sh}=k_sk_{hs}k_fk_{td}\cdot0.48\times10^{-3}
```

```math
k_{hs}=2.00-0.014H
```

5 天前开始干燥的混凝土，收缩结果乘 1.2（规范原文）。

## 输出定义

| 输出 | 单位 | 说明 |
| --- | --- | --- |
| `ψ(t,ti)` | - | 徐变系数（无量纲） |
| `εsh` | µε（负值） | 干燥收缩应变 |
| `εau` | µε | 恒为 0（模型无自生项，为对齐矩阵保留） |

单点计算生成 0 到 10000 天的混凝土龄期曲线。

## 使用限制

- 系数模型：不算柔量、弹性模量与结构响应；加速养护 1 天折 7 天的 ti 调整是可选指引，本应用未采用。
- Al-Manaseer & Prado (2015) 在 RILEM/NU-ITI 六模型对比中把 AASHTO 排在收缩、徐变双项最末；按规范评述预期 ±50% 误差，关键结构应做材料试验。
- 本计算器给出经验模型预测，不替代材料试验、项目专项分析或注册工程师判断。
